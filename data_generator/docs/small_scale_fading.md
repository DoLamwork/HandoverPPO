# Rician/Rayleigh small-scale fading with Doppler

The simulator applies flat small-scale fading after antenna gain, pathloss, and
shadow fading. It uses the already-realized spatial link state:

```text
is_los = True   -> Rician fading
is_los = False  -> Rayleigh fading
```

No second LoS probability is generated by this model. In legacy
`PATHLOSS_MODE = "average"`, no branch exists and small-scale fading is not
applied.

## Diffuse component

Each UAV-to-sector link has an independent sum-of-sinusoids process with `M`
isotropically distributed arrival directions:

```text
g(t) = (1 / sqrt(M)) sum_m exp(j (2 pi f_m t + phi_m))
```

For scatterer direction `s_m` and horizontal UAV velocity `v`, its Doppler is:

```text
f_m = (f_c / c) dot(v, s_m)
```

Random initial phases make `g(t)` approximately circular complex Gaussian.
Therefore its envelope is Rayleigh-distributed and its mean power is one.

## LoS component and Rician channel

The direct-path Doppler uses the velocity projected onto the three-dimensional
unit vector from the BS to the UAV:

```text
f_D,LOS = (f_c / c) dot(v, d_hat_BS_to_UAV)
```

The LoS channel is:

```text
h_Rician(t) = sqrt(K / (K + 1)) exp(j phi_LOS(t))
             + sqrt(1 / (K + 1)) g(t)
```

The NLoS channel is:

```text
h_Rayleigh(t) = g(t)
```

Both branches are normalized to unit mean power. The default LoS K-factor is
10 dB and is configurable; it is a baseline parameter, not a calibrated value
for every urban environment.

## Power applied to RSRP and SINR

The instantaneous linear power gain is `|h(t)|^2`. The simulator samples the
channel internally and averages power in the linear domain:

```text
G_bar = mean_q |h(t_q)|^2
G_fading,dB = 10 log10(G_bar)
P_rx = P_rx,large-scale + G_fading,dB
```

With the defaults, every 10 ms output step contains ten internal samples at
1 ms spacing. This retains Doppler-dependent variation without logging a
sub-millisecond dataset. RSRP and every signal/interference term in SINR use
the same averaged link gain.

Radio calculations and all-BS logging can evaluate a link more than once in one
frame. The cache key `(ue_idx, sector_idx)` and frame number ensure that these
calls reuse exactly the same fading sample instead of advancing the channel twice.

Large-scale LoS/NLoS and shadow fading remain shared by co-sited sectors. The
small-scale channel is stored per sector because sectors use different antenna
ports and transmit signals.

## Doppler at 2.1 GHz

Maximum Doppler magnitude is:

```text
f_D,max = v f_c / c
```

Approximate values for the configured carrier are:

| Speed | Maximum Doppler |
|---:|---:|
| 30 km/h | 58 Hz |
| 60 km/h | 117 Hz |
| 90 km/h | 175 Hz |
| 120 km/h | 234 Hz |

The direct-path Doppler can be smaller because it depends on the flight
direction relative to the BS.

## Configuration

```python
ENABLE_SMALL_SCALE_FADING = True
RICIAN_K_FACTOR_DB = 10.0
FADING_NUM_SINUSOIDS = 16
FADING_SUBSTEP_MS = 1.0
SPEED_OF_LIGHT_M_S = 299792458.0
```

Set `ENABLE_SMALL_SCALE_FADING = False` to recover the previous large-scale
received-power calculation.

## Current limitations

- The channel is flat over the complete 10 MHz band; delay spread and
  frequency-selective fading across PRBs are not modeled.
- The Rician K-factor is fixed instead of depending on elevation angle,
  environment, or distance.
- Diffuse scatterers are isotropic and remain associated with a link.
- The 10 ms value is internally averaged but no separate 3GPP Layer-1/Layer-3
  measurement filter or handover time-to-trigger is applied yet.
- Independent per-sector small-scale channels do not model spatial correlation
  between antenna panels or between multiple UAVs.
